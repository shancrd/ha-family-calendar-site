Privacy Policy

Family Calendar for Home Assistant · Last updated: 1 November 2026

Data accessed

When the account owner signs in with Google, the app requests access to Google Calendar so it can read events and create new events in the owner's calendars.

How the data is used

Calendar data is used only to display the household's events on its own Home Assistant dashboards (wall tablet and phones) and to create events that a family member adds there.

Storage and sharing

  • Calendar data and the Google sign-in token are stored only on the household's own Home Assistant server, on its home network.
  • No data is sold, shared with, or sent to any third party.
  • No data is used for advertising, analytics, or training any model.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The account owner can revoke access at any time at myaccount.google.com/permissions, or by removing the Google Calendar integration from Home Assistant, which deletes the stored token.

Contact

Questions about this policy: open an issue at github.com/shancrd/ha-family-calendar-site/issues.
